# Your JMeter plans (Week 6)

Save your test plans and data here (Days 26–30):

```
jmeter/
├── hello.jmx                 ← Day 26
├── browse.jmx                ← Day 27
├── shopper.jmx               ← Day 28 onwards
├── data/users.csv            ← load-test accounts
├── data/search-terms.csv
├── results/                  ← run output — ignored by Git, delete between runs
└── PERFORMANCE_REPORT.md     ← Day 30
```

The instructor's version is in [`../reference/jmeter/`](../reference/jmeter/), including
`check-thresholds.js`, which turns a JMeter report into a pass/fail exit code.
